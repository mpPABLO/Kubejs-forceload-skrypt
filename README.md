This KubeJS NeoForge 1.21.1
script automatically runs the `/forceload` command,
forcing the game to keep a chunk loaded even when the player moves away.
It was created for the "Compact Tunnels" mod (https://www.curseforge.com/minecraft/mc-mods/compact-tunnels),
but feel free to use it.
The script location is `kubejs/server_scripts/(here)`.
